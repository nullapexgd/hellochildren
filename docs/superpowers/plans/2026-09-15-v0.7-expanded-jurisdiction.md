> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand the 21-chapter v0.6 book into a defensible, funny 32-chapter v0.7 organized into six parts, with new storage, memory, hardware, firmware, networking, waiting, wakeup, and interrupt jurisdictions.

**Architecture:** Markdown source files remain authoritative. Existing late chapters are renumbered once near the beginning, then five manuscript clusters add and redistribute material in dependency order. A new `book/contents.txt` manifest interleaves six part-divider files with chapter files for deterministic Markdown, HTML, and EPUB assembly. Evidence changes travel with the prose they support; publication metadata and frozen outputs are produced only after manuscript review.

**Tech Stack:** Markdown, POSIX shell, Pandoc, Lua, HTML/CSS/JavaScript reader, Apple Platform Security and Developer documentation, Apple open-source XNU, standards documentation, and explicitly labeled public reverse engineering.
